# 📄 Currículo Online - Vinicius Magalhães

Este projeto é uma **página web de currículo** desenvolvida em **HTML5 e CSS3**, com ícones da biblioteca **Font Awesome**.  
O objetivo é apresentar minhas experiências profissionais, escolaridade, cursos e qualificações

---

## 🎯 Funcionalidades

✅ Foto de perfil e informações de contato  
✅ Seções de **Experiência Profissional**, **Escolaridade**, **Cursos** e **Habilidades**  
✅ Links para **Email**, **LinkedIn** e **GitHub**
